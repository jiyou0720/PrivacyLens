# PrivacyLens Chrome Web Store 등록 문구

## 제품 세부정보

- 패키지 제목: `PrivacyLens`
- 패키지 요약: `회원가입 화면의 개인정보 수집 항목과 동의 내용을 분석해 확인이 필요한 위험과 관련 법령 근거를 알려줍니다.`
- 카테고리: `생산성`
- 언어: `한국어`

## 설명

PrivacyLens는 회원가입 및 개인정보 동의 화면에서 제공 전에 확인해야 할 내용을 정리해 주는 개인정보 보호 보조 도구입니다.

주요 기능

- 현재 페이지의 개인정보 입력 필드와 동의 항목 탐지
- 연결된 이용약관 및 개인정보 처리방침 본문 분석
- 확인이 필요한 항목과 규칙 기반 위험 점수 표시
- 관련 개인정보 보호법 조항과 핵심 요약 제공
- 분석 결과를 PrivacyLens 웹서비스의 서비스별 제공 이력으로 전달
- 웹서비스에서 TXT, MD, PDF 동의문 분석 지원

개인정보 보호

PrivacyLens는 사용자가 입력한 이름, 이메일, 전화번호 등의 실제 값을 읽거나 저장하지 않습니다. 화면에 표시된 입력 필드의 종류와 공개된 동의문 및 약관 텍스트만 분석합니다. 웹서비스로 전달된 분석 결과는 같은 브라우저의 세션에서 확인할 수 있습니다.

이용 안내

분석 결과는 법률 판단이 아닌 확인 보조 정보입니다. 사이트 구조, 접근 권한, 동적 콘텐츠 또는 문서 길이 제한에 따라 일부 내용이 반영되지 않을 수 있으며, 이 경우 분석 불충분 상태를 표시합니다.
